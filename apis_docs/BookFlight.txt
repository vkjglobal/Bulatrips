BookFlight
API / pre-booking / BookFlight
This API helps in the process of booking an itinerary by letting users pass Traveller information. It enables users to provide details like passenger name, contact information etc., Passengers should verify the specific naming rules and character limits for surnames when booking flights, as they are subject to each airline's policy. This ensures that the provided surname complies with the airline's system and avoids any issues during check-in or boarding.avatar
