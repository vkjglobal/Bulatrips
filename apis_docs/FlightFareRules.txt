FlightFareRules
API / pre-booking / FlightFareRules
This API provides the rules for the selected itinerary. It provides details of the specific requirements and restrictions associated with a particular fare. Fare Rules API response will provide the complete information regarding baggage, Airline, penalty and complete fare rules. Points to be noted: Fare rule API should be performed from Fare Source Code(FSC) of Revalidation Response to get accurate Fare Rule as per Airline. Fare Rule API(Web-Fare), we are passing the airline fare rule URL in Response for LCC carrier.avatar
POST
https://restapidemo.myfarebox.com/api/v1/FlightFareRules
