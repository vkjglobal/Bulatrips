Search v2 - Branded Fares
API / pre-booking / Search v2 - Branded Fares
Search V2 is the latest and upgraded version of Search V1, with a major difference in the response structure, which is now aligned with the endpoint used based on the results that change between V1 and V2. A key feature introduced in this version is Branded Fares/Fare Families, allowing users to view specific fare offerings from airlines. This API version has been regularly updated over the past 2.5 years to ensure that users receive the latest data, including direct access to branded fares from airlines. Search V2 provides a streamlined way to access airline data and search for the lowest and best fares. The request requires only a few parameters, while the response provides extensive information with many parameters.avatar

https://restapidemo.myfarebox.com/api/v2/Search/Flight
