6. DATA NEEDED FROM API
For EACH leg (departure AND return), provide all fare options (1-4) with:
•	Price per leg
•	Fare Type (Public/Private/Webfare) - auto-determined
•	Fare Family name (Lite/Saver/Value/Flex/Business) - if available
•	Checked baggage: Yes/No + kg amount
•	Cabin baggage: Yes/No + kg amount
•	Refundable: Yes/No
•	Change fee: amount or "Free" or "Not allowed"
•	Meal inclusion: Yes/No
•	Seat selection: Free/Paid/At check-in
