Void API
API / post-booking / Void API
Create Post Ticketing Request API is performed to accept the “VoidQuote” and submit the “Void” request for a specific booking reference generated by Mystifly. “Void” PTR response will provide you the PTR ID generated.avatar
POST
https://restapidemo.myfarebox.com/api/PostTicketingRequest

Request Parameters

List of API Request Parameters with their details
Parameter	Example / Type	Description
{		
"ptrType":	"Void"	Indicates the PTR functionality requested for
"mFRef":	"MF15171220",	Mystifly reference starts with MF followed by 8 digits.
"AllowChildPassenger":	True/false,	Pass "true" only if any CHILD pax associated with the booking.
"passengers": [		Passenger details associated with the booking.
{		
"firstName":	"Alex",	First Name of the passenger associated with the booking.
"lastName":	"Tan",	Last Name of the passenger associated with the booking.
"title":	"MR",	Tittle of the passenger associated with the booking.
"eTicket":	"5654345667787",	e-ticket number of the passenger associated with the booking.
"passengerType":	"ADT"	Passenger type ADT/CHD/INF associated with the booking.
}		
],		
}
