Void Request Search API
API / post-booking / Void Request Search API
Search Post Ticketing Request API is performed to check the status of the PTR ID generated from the “Void” response created, this API also gives the information about the Booking status, Passenger details and Void amount associated for the booking.avatar
POST
https://restapidemo.myfarebox.com/api/Search/PostTicketingRequest

Request Parameters

List of API Request Parameters with their details
Parameter	Example / Type	Description
{		
"ptrType":	"Void",	Indicates the PTR functionality requested for
"mFRef":	"MF15171220",	Mystifly reference starts with MF followed by 8 digits.
"PTRCategory":	"All"	None, NotRead, Read, All, Please pass by default pass All.
"PTRStatus"	"None"	None, Requested, InProcess, Completed, Rejected, QuoteChanged
"PTRId":	5287,	PTR ID is Unique reference number generated for the VOID request.
"ShowProcessingMethod":	True,	True indicates if the PTR ID was processed Auto/Manuall, if False no tag passed
"Page":	1	Page number to view PTR ID transaction details min 1 max of 25 records
}
